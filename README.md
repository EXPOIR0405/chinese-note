# 중국어 복습노트

중국어 수업에서 배운 발음과 문화를 차시별로 모아두는 개인 복습 사이트입니다.

**사이트:** https://chinese-note-brown.vercel.app/

## 개발 배경

중국어 수업을 듣기 시작했는데, 수업 때 노트한 내용을 매번 정리하고 기록하는 게 생각보다 너무 힘들었습니다. 들을 때는 다 알 것 같아도 며칠 지나면 뜻이나 성조가 금방 날아갔습니다.

그래서 아예 웹사이트로 만들었습니다. 수업이 끝나면 배운 내용을 Claude에게 말로 편하게 이야기합니다. 그러면 Claude가 데이터 파일에 정리해 넣고, 사이트에 자동으로 반영됩니다. 직접 입력하지 않아도 복습 자료가 쌓입니다.

특히 이 수업은 "중국어는 발음이 80%"라고 할 만큼 발음을 중요하게 다룹니다. 그래서 사이트도 성조와 발음을 눈과 귀로 반복할 수 있게 만들었습니다.

## 주요 기능

| 탭 | 내용 |
|---|---|
| 오늘의 복습 | 다음 수업까지 남은 날(D-day), 지난 수업 요약, 헷갈린다고 표시한 단어 |
| 발음 | 성조 4개 음높이 그래프, 선생님 팁과 수업 메모, 성모·운모 표, 헷갈리는 발음 비교 (zh/z, x/sh, ü/u 등) |
| 단어 카드 | 한자 → 병음·뜻 순서로 뒤집는 카드. 차시별 보기, '헷갈려요' 표시 |
| 성조 퀴즈 | 소리를 듣고 몇 성인지 맞히기 |
| 문화 노트 | 수업에서 배운 중국 문화. 4대·8대 요리 표 포함 |
| 수업 기록 | 차시별로 배운 것 목록 |

- 병음은 성조마다 색이 다릅니다. 1성 빨강, 2성 주황, 3성 초록, 4성 파랑, 경성 회색.
- 🔊 버튼을 누르면 브라우저에 내장된 중국어 음성(TTS)으로 소리가 나옵니다. 녹음 파일은 따로 없습니다.
- 수업에서 직접 배운 것과 Claude가 보충한 것을 구분해서 표시합니다. 보충한 것에는 "수업 메모", "Claude 보충" 표시가 붙습니다. 수업 메모와 사실이 다른 부분은 문화 노트에 확인 메모로 남깁니다.

## 업데이트 기록

### 2026-10-19 · 사이트 첫 공개

- 샘플 페이지로 화면 구성을 확인한 뒤 실제 사이트를 만들었습니다.
- GitHub 저장소를 만들고 Vercel에 연결했습니다. push하면 자동으로 배포됩니다.

### 1차시 (10/13) · 성모·운모, 그리고 중국이라는 나라

- **발음:** 성모 21개와 운모를 배웠습니다. 중국어는 발음이 80% 정도로 중요합니다. 3성 + 3성은 2성 + 3성으로 읽습니다 (你好 → Ní hǎo).
- **인사:** 很高兴认识你 (만나서 반가워요), 我也很高兴认识你 (저도 만나서 반가워요). 认识你는 처음 만났을 때만 씁니다.
- **문화**
  - 56개 민족
  - 오성홍기: 큰 별은 공산당, 작은 별 4개는 네 계급
  - 공산당의 당기
  - 1949년 10월 1일 건국: 마오쩌둥이 천안문에서 선포했고, 국경절에는 천안문 광장에서 국기를 흔듭니다.
  - 월요일 국기 게양식과 빨간 스카프(红领巾)
  - 국가 '의용군 행진곡'

### 2차시 (10/15) · 식당에서 주문하고 계산하기

- **표현:** 想, 什么, 吃, 请, 要, 一点, 这个, 那, 还是, 可以
- **음식:** 面条, 饺子, 包子, 米饭, 羊肉串, 牛肉面, 麻辣烫, 锅包肉
- **맛:** 苦 쓰다, 甜 달다, 辣 맵다
- **계산:** 服务员, 买单, 扫码, 付款, 一共
- **인사:** 欢迎光临, 下次, 再来 (欢迎下次再来 다음에 또 오세요)
- **문화**
  - 현금 대신 QR로 결제 (위챗페이, 알리페이)
  - 식당에서는 买单만 말해도 계산이 됩니다.
  - 아침시장(早市)
  - 4대·8대 요리: 지역별 맛의 특징과 대표 요리
- **발음 메모:** 一의 성조 변화 (一共 yígòng, 一点 yìdiǎn)

### 화면 개선

- 단어 카드 뒷면에 예문과 메모를 함께 보여줍니다. 긴 문장도 들어가도록 카드를 키웠습니다.
- 휴대폰처럼 좁은 화면에서 카드가 옆으로 넘치지 않도록 고쳤습니다.
- 문화 카드에서 병음이 세로로 끊기던 문제를 고쳤습니다.

## 구조

빌드가 필요 없는 정적 사이트입니다(HTML/CSS/JS). DB는 쓰지 않습니다.

```
index.html   화면 뼈대
style.css    디자인 (라이트·다크 모드)
app.js       데이터를 읽어서 화면을 그림
data/        배운 내용 전부
```

내용은 전부 `data/` 폴더의 JSON 파일에 있습니다. 수업이 끝나면 JSON만 고칩니다.

| 파일 | 내용 |
|---|---|
| `data/schedule.json` | 수업 날짜. `tentative: true`는 예상 날짜 |
| `data/lessons.json` | 차시별 요약과 배운 것 목록 |
| `data/words.json` | 단어 카드. `syl`은 `[병음, 성조]` 목록 (경성은 0). `note`는 카드 뒷면 메모 |
| `data/sounds.json` | 배운 성모·운모, 발음 팁, 비교 발음, 성조 퀴즈 문제 |
| `data/culture.json` | 문화 노트. `check`는 확인 메모, `extra`는 Claude 보충, `table`은 요리 표 |

'헷갈려요' 표시는 브라우저(localStorage)에만 저장됩니다. 그래서 휴대폰과 컴퓨터 사이에 공유되지 않습니다. 기기 간에 맞춰야 할 때가 오면 Supabase를 붙일 계획입니다.
